# NGC source adapter (P049)

El catálogo ofrece UI y CLI con acceso público o con entitlement; este perfil no anuncia consulta hasta fijar un contrato y credenciales verificables.

Official reference: https://docs.nvidia.com/ngc/latest/ngc-catalog-user-guide.html

The adapter owns a distinct generated manifest and profile. It never calls a provider API unless that origin is declared in the generated manifest. Supported methods: none.
