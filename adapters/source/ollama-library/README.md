# OLLAMA_LIBRARY source adapter (P049)

/api/tags describe el runtime Ollama local y no se toma como API estable del catálogo web Library; se deshabilita scraping.

Official reference: https://docs.ollama.com/api/introduction

The adapter owns a distinct generated manifest and profile. It never calls a provider API unless that origin is declared in the generated manifest. Supported methods: none.
