# OPENXLAB source adapter (P049)

La documentación disponible describe UI, SDK y descarga de repositorios, pero no un contrato estable de búsqueda pública para este adapter; no se hace scraping.

Official reference: https://openxlab.org.cn/docs/en/models/%E4%B8%8B%E8%BD%BD%E6%A8%A1%E5%9E%8B.html

The adapter owns a distinct generated manifest and profile. It never calls a provider API unless that origin is declared in the generated manifest. Supported methods: none.
