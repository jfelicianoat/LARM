# Benchmarks, comparación y promoción

ExecutionFingerprint RFC8785/SHA256 sobre componentes {artifact_bundle_hash, revision, runtime_id, runtime_version, installation_hash, backend, driver_versions, hardware_fingerprint, launch_profile_hash, tokenizer_hash, chat_template_hash, protocol, protocol_profile_hash, effective_generation}. Cada componente tiene value, status VERIFIED/DECLARED/UNAVAILABLE, evidence_ref. No inventar missing. Snapshot se fija en momento de ejecución; no leer catálogo posterior para informe. Exportar a Model Drift preserva sus capas A/B/C y estados verificado/declarado/no_disponible; extras técnicos en extensión versionada, no inyectarlos en esquema Broker actual.

Comparación requiere compare_axis explícito: runtime_version, model_revision, backend, launch_profile. Sólo componentes del eje pueden cambiar; resto exactamente iguales, fixture/suite/settings hashes iguales y evidencias suficientes. runtime_version permite installation_hash dependiente de versión, pero no modelo/driver/OS/context. model_revision permite bundle/revision/tokenizer/template propios del modelo, y mantiene input/tarea/params/runtime/backend/hardware; marcar esto como comparación modelo, no reproducción. Campos UNAVAILABLE que importan al control=>INCOMPARABLE; no exigir hash total igual para comparar versiones porque el eje cambia. Igualdad total sólo replay/reproducción. Export incluye differing_components y limitations.

Technical benchmark real usa 1 warmup+5 repeticiones, seed42 cuando soportado, temperature0, top_p1, batch1, timeout1800s. Cold load proceso detenido controlado sin lease; warm evita false cold. Raw timings monotonic nanoseconds en PCIA, artifacts SHA, snapshot/provenance; reportar median, p95 nearest-rank, mean, stddev, pico RAM/VRAM, errores. No restar tiempos red de otra máquina sin sincronización; medir duraciones local worker. TTFT desde envío hasta primer contenido semántico, no keepalive/role; throughput generación=outputtokens/(lasttoken-firsttoken) con n>1, prompt eval runtime si expuesto o null. No estimar tokens a caracteres para afirmar benchmark. Sin streaming TTFT=null reason UNSUPPORTED, no latencia final renombrada.

fixtures/benchmark-suites.json fija entradas y oracles. Smoke no mide calidad: texto UTF8 no vacío+finish; JSON válido contra schema; tools nombre+args válidos y llamada sin ejecutarla; embeddings dimensión fija+finite; image decodificable, resoluciónexacta; video contenedor fps/duración y frames decodificables; ASR texto no vacío sobre WAV calibrado; TTS WAV no vacío sample_rate y duración; decision alternativas finitas/probabilidades nativas cuando así declaradas. OCR/detection/segmentation/tensor usan contratos de output shape y finitud. Suite requiere las capacidades anunciadas; capabilities ausentes se clasifican UNSUPPORTED, capacidades anunciadas que fallan son FAIL. Tolerancias numéricas abs1e-5/rel1e-4 sólo fixtures computacionales fijos, no exigir imagen generativa bit exacta. Inputs binarios se generan determinísticamente por herramientas de fixtures y quedan hashlocked antes de run. Modelo mínimo licenciado se lockea con fuente/revision/artifacts en P000; no elegir alias latest en test real.

TechnicalFit 0..100: gates PASS primero. Memoria=clamp100*(1-required/budget); backend CPU40/GPU80/NPU80/hybrid70 sólo efectivo evidenciado; speed=100*min(1, throughput/target) donde target LLM20tok/s, embedding100items/s, ASR RTF<=1, imagen1/30s, TTSRTF<=1, tensor100/s, video realtime<=1; si no medido speed=null y score provisional sin imputar. Storage=100*min(1, observed_MBps/200) si medido; context=100*min(1, effective/required). Maturity=100 sólo release estable con contract suite PASS, experimental50, nueva sin suite=null. Stability=100*(1-failed/total) de últimas20 ejecuciones de mismo fingerprint, mínimo5 o null. Pesos memory30/backend20/maturity10/speed15/storage10/context10/stability5, missing se elimina del denominador y reporta coverage; coverage<60 no auto-recomendar. Nunca score a incompatible/unknown.

EvaluationScore sólo importado de Lab/Drift con suite/revision/dataset hash y restricciones; sin evaluación=null y UI NO EVALUADO. Recommendation con evaluación comparable=.6Technical+.4Evaluation; sin ella ranking técnico declarado, sin score de calidad. Popularidad/downloads/licencia no puntúan evaluación. Tie TechnicalFit desc, headroom desc, variant_id/runtimeversionid asc.

Promoción candidate->default requiere load, health, smokes, protocolqualification, benchmarkcomparison PASS, licencia/trust aprobado, refs integras, ningún gate desconocido. Regresión FAIL si throughput cae >10%, latency o memory sube >10% en median y no cubierto por tolerance1%/sampling variance declarada; fallos funcionales nuevos o fallback=>FAIL inmediato. Señal ruidosa intervalos superpuestos=>INCONCLUSIVE y no auto-promote. Certificación funcional necesaria si la default previa estaba certificada; no convertir ausencia en aprobación. Pinning gana y evita auto-promoción. DB default switch atómico + outbox; rollback conserva versión anterior, deja leases actuales terminar, siguientes leases usan anterior.

Model update detect->candidate_revision->download+verify->compatibility->load/smoke->benchmark comparison->external_eval cuando requerida->approve->promote. Nunca modificar bytes o alias de default en sitio; retención al menos último default válido y cualquier referencia/lease. Runtime update sigue misma puerta; P032 implementa mecanismo que permanece bloqueado hasta evidencias de P117.

Evaluation scale es {minimum,maximum,direction,unit}; maximum debe ser mayor que minimum y score debe estar en rango. Normalizar0..100 con 100*(score-min)/(max-min) para HIGHER_BETTER e invertir para LOWER_BETTER. Escala inválida se rechaza, no se adivina. Sin score conservar null.

ExecutionFingerprint incluye artifact_storage_volume_keys ordenados para controlar el almacenamiento en comparaciones de carga. Hash de componentes usa name,value,status; evidence_refs y sus timestamps son trazabilidad separada y no alteran identidad. Cambiar orden de enumeración, letra de unidad o LUID de sesión no cambia huella. Una prueba de reproducción sólo afirma equivalencia sobre componentes observables.

Incertidumbre técnica cerrada: con las5 repeticiones calcular IC95% de media como mean±2.776*sample_stddev/sqrt(5), truncar límite inferior a0 para métricas no negativas. Regresión de median>10% con IC de las medias solapados es INCONCLUSIVE; sin solapamiento es FAIL. Comparación dentro del umbral sin fallos nuevos es PASS. Menos5 muestras válidas, métrica no medible o duración0 no da PASS de esa métrica: reportar razón y bloquear promoción si es requisito. TTFT streaming y throughput no se rellenan a partir de respuestas no-streaming.
