# Perfiles externos y descubrimiento reproducible

runtime-profiles.json enumera20 runtimes, propietarios, formatos y candidatos de sondeo; no afirma que esos candidatos funcionen en PC IA. No se ha entregado inventario de esa máquina. P000 captura hardware, software y topología y fija toolchains/fixtures/releases legales. P099 obtiene hechos con procedimiento cerrado: versión exacta, documentación o OpenAPI de esa versión, probe harmless y transcripción SHA256. No se declara compatible un backend por preferencia.

Profile lock requiere todos los profile_required_fields. Cada comando, flag o endpoint registra fuente primaria, revisión/commit, captura, content_hash, request/response/error fixtures y test de qualification. Bibliotecas sin HTTP usan SDK fijado en worker externo y sidecar. Si falta --version, leer metadata de paquete o file version/hash; versión de Python no es versión de ComfyUI. No escanear LAN. Versión desconocida permanece UNQUALIFIED; activar nuevo perfil exige contract suite y smokes reales, sin modificar Core. Una captura de documentación latest sin revisión no basta.

Fuentes comprometidas: HF, ModelScope, Kaggle, Ollama Library, GitHub Releases, OpenXLab, NGC, Civitai, Foundry catalog, Lemonade registry, HTTP(S), Git/LFS, local y UNC/NAS/private. Source adapter implementa las firmas de adapter-methods.json. Búsqueda inaplicable para URL/local devuelve LarmError UNSUPPORTED_CAPABILITY y anuncia modo import; no devuelve vacío fingiendo búsqueda válida. Cada ficha contiene base/version, auth soportada, query/paginación, revisión inmutable, manifest/LFS size/checksum, bundle detection, errores, límites, licencia y pruebas. Adapters de catálogo y runtime host son distintos aunque compartan origen. Ollama Library no es el daemon.
